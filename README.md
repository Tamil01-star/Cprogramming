# C Programming Interview Questions & Answers

[![Deploy to GitHub Pages](https://github.com/Tamil01-star/Cprogramming/actions/workflows/deploy.yml/badge.svg)](https://github.com/Tamil01-star/Cprogramming/actions/workflows/deploy.yml)

> Complete **201 C Programming Interview Questions & Answers** curated from campus placement question banks, with easy-to-understand explanations, clean C code examples, step-by-step dry run trace tables, output predictions, and debugging breakdowns.

**Live Website:** [https://tamil01-star.github.io/Cprogramming/](https://tamil01-star.github.io/Cprogramming/)

---

## Features

- **201 Total Questions**: Complete coverage across 5 placement sections without skipped or duplicate questions.
- **Section 1: Technical Interview Questions (51 Questions)**: Core C fundamentals, pointers, memory allocation, storage classes, structures, unions, and enums.
- **Section 2: Programming Logic & Pseudocode (40 Questions)**: Prime numbers, palindromes, Armstrong/Strong/Neon numbers, searching, sorting, and pattern printing.
- **Section 3: Placement Coding & Hard Dry Run (60 Questions)**: In-depth code tracing with step-by-step execution trace tables and pointer arithmetic.
- **Section 4: Output Prediction Questions (30 Questions)**: Pre vs post increment, operator precedence, evaluation orders, and scope rules.
- **Section 5: Debugging Questions (20 Questions)**: Error identification, root causes, and verified bug fixes.
- **Study Mode**: Single-question card focus with Next/Previous buttons and keyboard navigation (`←` and `→`).
- **Browse All Mode**: Continuous scrollable list for fast pre-interview revision.
- **Instant Search**: Live search across question titles, topics, code snippets, and answers.
- **Study Progress Tracking**: "Mark as Mastered" and "Bookmark" toggles with local storage persistence.
- **Clean Light Theme**: Custom light theme matching glowing blue, cyan, and violet aesthetics with frosted glassmorphism and the uploaded theme wallpaper.

## Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Tamil01-star/Cprogramming.git
   cd Cprogramming
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Deploy to GitHub Pages:**
   ```bash
   npm run deploy
   ```
